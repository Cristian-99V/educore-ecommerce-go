# educore-ecommerce-go
Propuesta arquitectónica de un sistema de gestión de comercio electrónico desarrollado en **Go (Golang 1.22+)** bajo el paradigma de **Programación Funcional** (*Functional Core, Imperative Shell*). El sistema gestiona la venta de cursos de capacitación, validación de cupones por compra múltiple (`> 1 curso`) y cálculo determinista de envío.
